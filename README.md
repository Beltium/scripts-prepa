# Scripts Prépa

A collection of Python scripts developed during my MPSI preparatory classes.

This repository is mainly used to keep, organize, and access my scientific computing scripts throughout my preparatory studies.

## Contents

The repository contains scripts related to:

* 📊 Statistical analysis and uncertainty calculations
* 🎲 Random processes and Monte Carlo simulations
* 📈 Data visualization with Matplotlib
* 🔢 Numerical calculations with NumPy
* ⚛️ Physics applications
* 🧮 Mathematical computations

More scripts will be added as my studies progress.

## Requirements

The scripts are written in Python and mainly rely on:

* [NumPy](https://numpy.org/)
* [Matplotlib](https://matplotlib.org/)

Additional dependencies may be required for some scripts.

## Usage

Each script is designed to be run independently unless otherwise specified.

For example:

```bash
python script_name.py
```

The scripts are primarily intended for educational purposes and for use during my MPSI studies.
